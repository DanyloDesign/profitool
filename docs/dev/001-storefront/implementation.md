# 001 · Profitool, витрина магазина инструмента — Implementation

- **Статус:** сделано, часть решений позже переработана в 002
- **Автор:** AI-агент (Claude Code)
- **Заведено:** 2026-09-20

## Что построено

Каркас магазина целиком, проходится насквозь: главная → каталог → карточка → корзина →
оформление → подтверждение. Две локали, 49 позиций в восьми категориях.

- Next.js 16.3.5, React 19.2.8, TypeScript strict, Tailwind v4.3.3.
- Локаль сегментом URL, `/` редиректит на `/ua` через `next.config.ts`.
- Фильтры каталога в `searchParams`: категория, бренд, платформа, цена, наличие, питание,
  сортировка. Ссылка на отфильтрованную выдачу работает.
- Корзина, сравнение и выбранная платформа в zustand с сохранением в localStorage.
- Чекаут одним экраном: react-hook-form + zod, три способа доставки, живой пересчёт итога.
- Подбор по аккумуляторной платформе — главная функция магазина, вынесен на главную,
  в фильтры и в карточку товара.

## Данные

`src/data/products.ts` — реальные модели с настоящими характеристиками: Makita HR2470,
Bosch GBH 2-26 DFR, DeWalt DCD791D2, Milwaukee M18 FPD2, Metabo KHE 2660 и далее. Цены в гривне,
диапазон 390–21 800 ₴. Ярлыки характеристик вынесены в общий словарь, значения хранятся строкой
либо парой ua/ru там, где единицы расходятся («об/хв» против «об/мин»).

## Три поломки, которые стоили времени

1. **Функции через границу server → client.** Словарь содержит функции склонения, React их
   не сериализует, страница падала с `chunk.reason.enqueueModel is not a function`. Решено
   провайдером локали: вниз уходит строка, словарь клиент собирает у себя.
2. **Blender 5.2 переименовал API.** `use_auto_smooth` убран в 4.1, солвер булевой операции
   больше не знает `FAST`. Обе правки лежат в `tools/products/render_products.py`.
3. **Пересвет в рендерах.** Ключевой свет на 1700 Вт выбивал блики в белый, корпус выглядел
   пластмассовым. Помогли широкий источник на 420 Вт и экспозиция −0,35.

## Что решено не делать

- Отзывы и рейтинги: без реальных данных это декорация, которая бьёт по доверию.
- Бэкенд и оплата: заказ заканчивается экраном с номером.

**⚠ Флаги:** нет. Сетевых вызовов, ключей и внешних сервисов в рантайме нет.
