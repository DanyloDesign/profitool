## Сделано

Все одиннадцать пунктов плана закрыты. Собрано 96 стеклянных и фотографических изображений
(48 + 48), вес каталога картинок ужат с 54 до 29 МБ пережатием до 760px.

## Починенные дефекты

- **Бесконечный цикл на странице сравнения.** Селектор `useCart((s) => s.items.map(...))`
  возвращал новый массив на каждый рендер, React ругался на нестабильный снапшот. Подписка
  переведена на `items`, производные значения считаются после.
- **Next отдавал старые картинки.** Файлы перезаписывались под теми же именами, оптимизатор
  и браузер держали копии. Решено суффиксом `-photo` в имени; при перегенерации на месте
  обязательно чистить `.next/cache/images`.
- **Query-строка у `next/image`.** Версионирование через `?v=2` падает без `images.localPatterns`
  в конфиге, поэтому версия вынесена в имя файла.
- **Мобильная вёрстка.** Поиска на телефоне не было вовсе — вынесен отдельной строкой под шапку.
  Каталог и категории переведены на две колонки с 390px, герой перестроен: картинка сверху,
  текст под ней, дыра между блоками убрана.
