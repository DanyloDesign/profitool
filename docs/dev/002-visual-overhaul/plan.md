# 002 · Переделка визуала под фидбек владельца — Plan

- **Статус:** сделано
- **Автор:** AI-агент (Claude Code)
- **Заведено:** 2026-09-20

1. Убрать JetBrains Mono, перевести цифры и подписи на Geologica с табличными цифрами.
2. Снять с фона сетку и зерно, увести фон в чистый чёрный.
3. Свернуть шапку в одну строку, служебные полосы удалить.
4. Вычистить карточку товара: только фото, бренд, название, цена.
5. Сократить главную до пяти блоков.
6. Скруглить формы, переписать кнопки на пилюли.
7. Отрендерить стеклянную версию всех восьми типов инструмента, поставить иконками разделов.
8. Снять адреса настоящих фотографий через браузер, скачать, вырезать фон, вписать в квадрат.
9. Развести пути: `-photo` для фотографий, `-glass` для иконок.
10. Проверить мобильную вёрстку на 390px и починить найденное.
11. Прогнать сборку и типы, написать документацию, сделать коммит.
