## Решения по расхождениям с макетом

1. **Отзывы и оценки не перенесены.** `CLAUDE.md` запрещает их без реальных данных. Блок «Відгуки» с оценкой 4,6
   в макете выдуманный. Вернуть можно, когда появятся настоящие.
2. **Полоса «ремонт, гарантія, повернення» на главной не перенесена.** Владелец забраковал такие блоки ранее,
   а обещания в ней (свой сервис на Подоле, 24–36 месяцев) в данных не подтверждены.
3. **«Оплата частинами», «Купити в один клік», «Повідомити про наявність» убраны.** Функций за ними нет.
4. **Данные из макета заменены настоящими.** Цена, остаток, описание, характеристики берутся из `products.ts`.
   Телефон, адрес и часы работы остались из словаря, а не из макета. В формах нет подставленных имён и почты.
5. **Шаг 3 плана (перевод хардкода на токены) отдельным коммитом не делался.** Компоненты переписаны сразу
   на токены и утилиты, `top-[92px]` исчез (везде `--header-h`). Осталось около 100 строк с размерами
   `text-[..]`, `h-[..]`. Полный перевод на шкалу отложен.
6. **Кабінет только рисунок.** Учётных записей на сервере нет, форма проверяет ввод и пишет об этом.

## Что нашлось по дороге

- **`backdrop-filter` на шапке схлопывал `position: fixed` внутри неё.** Мобильное меню имело нулевую высоту,
  затемнение под мега-меню не закрывало страницу. Размытие вынесено на отдельный слой.
- **Паттерн `mounted` заменён хуком `useMounted`** на `useSyncExternalStore`. `pnpm lint` был на 11 ошибок
  `react-hooks/set-state-in-effect`, стал на нуле. Закрытие меню при переходе тоже без эффекта.
- **Скриншот headless Chrome с окном 390px врёт**: минимальная ширина окна около 500px. Скрипт в `tools/shots/`
  эмулирует устройство, прокручивает страницу ради ленивых картинок, проверяет `scrollWidth` и битые `<img>`.
- **Шапка на 390px переполнялась на 23px** от широкого Unbounded. Закрыто новым лок-апом.
- **PowerShell 5.1 портит кириллицу** при массовой замене через `Get-Content` и `Set-Content`. Один раз испортил
  шесть файлов, откатил через git. Правила записаны в память сессий.
- **Старый `/icons/favicon.svg` остался в `public/`.** Ссылок на него нет, файл можно удалить.
