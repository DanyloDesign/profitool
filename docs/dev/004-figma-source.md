# 004 — Figma як джерело правок

## Запит
«Відкрий у Chrome цей сайт в HTML, а також зроби Figma файл, де я буду редагувати його замість артефакту.»

## Пропозиція
Захопити живу сторінку з `pnpm dev` у Figma через `generate_figma_design`, щоб отримати редаговані шари, а не картинку.

## План
1. `pnpm dev`, відкрити `http://localhost:3000/ua` у Chrome.
2. Створити файл у Figma (team «Данило Клименко's team»).
3. Захопити головну сторінку, перевірити скриншотом із Figma.

## Реалізація (2026-09-21)
- Файл: https://www.figma.com/design/j6o68DVJ8HNHO5LOINOBnq, головна сторінка — вузол `2:2`, 1800×3578.
- Скрипт захоплення вставлено в сторінку через консоль Chrome, код проєкту не змінювався.
- Дефект: липка панель порівняння потрапила в захоплення посередині сторінки й перекриває заголовок «Категорії».
- Захоплення зроблено при ширині вікна 1800, мобільну версію не захоплювали.
- Інші сторінки (каталог, товар, кошик, оформлення) ще не захоплені.
