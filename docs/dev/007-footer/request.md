# 007 — Футер: контакти праворуч, оплата зліва

Фаза: REQUEST → IMPLEMENTATION (задача мала, власник дав точну схему).

## Запит дослівно
«Так, попрацюємо над футером. Мені потрібно, щоб ти номер телефону і адрес переніс на праву сторону, додав до них іконки. Бренди зробив нижче них, а зліва внизу зробив способи оплати типу віза мастеркард еплпей.»

## Як зрозумів
- Права колонка: телефон, адреса, години роботи з іконками (телефон, шпилька, годинник). Під ними бренди.
- Ліворуч лишається логотип; внизу ліворуч ряд знаків оплати: Visa, Mastercard, Apple Pay, Google Pay.
- Знаки оплати монохромні, у кольорі тексту футера, щоб не сперечатися з градієнтом. Офіційні кольорові логотипи — за окремим бажанням.
- Стиль, шрифти, іконки проєкту.

## Критерії
- Десктоп 1440/1024: контакти й бренди в правій колонці, оплата внизу ліворуч, © не губиться.
- Мобільний 390/360: логічний порядок стеку, без горизонтального скролу.
- Телефон — `tel:` посилання; обидві теми; UA і RU.
