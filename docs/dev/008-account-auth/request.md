# 008 — Кабінет: реєстрація і вхід окремими екранами

Фаза: REQUEST → IMPLEMENTATION (мала задача, поведінку власник описав точно).

## Запит дослівно
«Також мені не подобається, коли ти нажимаєш на іконку аккаунта. Регестрація і вхід на одному екрані. Потрібно, щоб було реєстрація і там десь зробити на ній кнопку, якщо у клієнта вже є аккаунт, тоді переключатися на вхід і назад так само.»

## Як зрозумів
- `/account` за замовчуванням показує лише реєстрацію.
- Під формою рядок «Вже маєте акаунт? Увійти» перемикає на вхід; на вході «Ще немає акаунта? Зареєструватися» повертає назад.
- Режим у URL (`?mode=login`), щоб працювали кнопка «Назад» і пряме посилання.
- Фокус після перемикання на перше поле, заголовок змінюється, без стрибка макета.
- Бекенду немає (заглушка лишається як була).
