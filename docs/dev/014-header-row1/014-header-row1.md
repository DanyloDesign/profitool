# 014 · Нижчий верхній ряд шапки без обведення кнопок

## 1. Request
Власник (2026-09-27): «В нас подвійний хедер. Зроби верхній шар з логотипом і кнопками меншим по висоті. З кнопок прибери обведення».

## 2. Proposal
Ряд 1 від 768px: 60 → 48px. Кнопки міста, підтримки, мови й теми без рамки (нова утиліта `bar-btn`), зона натискання лишається 44px, наведення міняє колір тексту. Логотип у ряду компактний: знак 32px (менше CLAUDE.md не дозволяє), слово 20px.
`default: ghost-btn з рамкою | chosen: текстові кнопки без рамки | why: прохання власника, службовий ряд не сперечається з другим`.

## 3. Plan
`globals.css` (`--header-l1`, `bar-btn`), `city-select.tsx`, `support-menu.tsx`, `theme-toggle.tsx`, `header.tsx` (LangSwitch, compact Logo), `logo.tsx`. Мобільна шапка (<768) не змінюється.
