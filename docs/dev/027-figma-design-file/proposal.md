# Proposal

One Figma file built through the Figma MCP from the code (src/app/globals.css, components) and the running site:

- Foundations: colour variables named like the CSS variables, with WEB code syntax `var(--…)`; size variables
  (radii, button heights and paddings, gutters, header heights); text styles for every t-* utility and the UI sizes;
  Brand/Gradient paint style; Shadow/Pop effect style.
- Components: 24 icons from icons.tsx, logo, Button (Signal/Ghost/Tint × S/M/L × Default/Hover/Disabled), IconButton,
  Field, Textarea, Checkbox, Radio, Chip, Choice, Badge, Toggle, Stepper, ProductCard, Header, Footer.
- Screens built from instances with real catalog data and product photos: Home, Catalog, Product, Cart, Checkout,
  Delivery at 1440 and 390.
