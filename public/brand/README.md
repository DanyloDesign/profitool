# Сюда кладём фирменные материалы

Агент читает эту папку сам. Имена файлов свободные, но лучше понятные.

| Что | Формат | Пример имени |
|---|---|---|
| Основной логотип | SVG, иначе PNG с прозрачным фоном от 2000px | `logo-full.svg` |
| Иконка / монограмма | SVG или квадратный PNG | `logo-mark.svg` |
| Версия под чёрный фон | SVG/PNG | `logo-full-dark.svg` |
| Монохром | SVG/PNG | `logo-mono.svg` |
| Носители: вывеска, визитка, упаковка, аватар | JPG/PNG | `ref-signage.jpg` |
| Шрифты бренда, если есть | woff2 / otf / ttf | `brand-font-regular.woff2` |

Фирменные цвета HEX и всё, что не файл, пишем в `docs/dev/003-brand-and-redesign/request.md`.
